# V20.3 — Purchasing & Replenishment
Base: accepted V20.2 main 3983613. Isolated preview only.

## Phase 1: explicit purchase-to-report handoff
- Existing vendor order line can identify one open consumable report by ID. A verified existing stock link may also identify incoming stock; never infer a new link by description alone. Explicit unlinked lines require matching description, recorded unit and confirmed compatible fitment.
- Purchase from the consumable detail opens the canonical vendor draft. If verified incoming exists, open orders instead of creating another draft. Saving rejects duplicate linked demand and repair/consumable dual allocation. Unrelated purchases remain possible.
- Partial receipt uses the existing receiving engine. For an explicitly linked report without stock, verified receipt stock becomes the report's stock link in the same save as inventory and order; failed save restores all three. Receiving does not close the report. Vehicle refill must still be confirmed.
- Mission Waiting omits an extra generic vendor-order action only when every outstanding line is explicitly represented by a waiting report. Mixed orders and unrelated lines remain visible. All orders remain in Inventory.
- Unknown amounts remain unknown; no automatic ordering. Multiple reports can still refer to shared stock; projection is not a stock reservation or a promise of enough material. A partially covered numeric target may remain Waiting until receipt and re-evaluation.
