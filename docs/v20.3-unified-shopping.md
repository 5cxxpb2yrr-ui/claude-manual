# V20.3 phase 2 — Unified shopping
Base: merged V20.3 phase 1 main 27ec110. Preview only.
- Existing repair/maintenance forecast and allocations remain authoritative. The shopping list adds explicitly quantified garage consumable targets and stock reorder targets; the highest target for a verified stock record wins. Subtract unreserved stock and compatible outstanding incoming orders once.
- Where the same material may cover repair work, vehicle replenishment or an ambiguous garage report, keep the stock target review-only rather than add a potentially duplicate recommendation. Qualitative consumables needing stock are review items, not invented quantities. Waiting, refill and confirm-stock reports do not generate speculative purchases.
- Stock-target purchases use the existing vendor form, with verified inventory ID and current uncovered quantity. Revalidate the remaining target on save, reject demand double allocation, and do not overwrite another order draft. No new persistent collection, automated purchasing or inventory mutations beyond existing order/receipt operations.
- This does not reserve supplies for reports, infer interchangeable materials, or estimate consumption rates. A partial receipt can leave an outstanding target; remaining quantities appear in Shopping. Consumption-based suggestions remain a separate next milestone.
- Existing automated recovery/browser tests remain mandatory, including preservation of all state on rollback. Added unit tests and browser coverage for target consolidation, quantity validation, and incoming quantities after reload.
